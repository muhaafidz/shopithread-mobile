## Locked architecture decisions

| Decision | Choice | Reason |
|---|---|---|
| App shape | Vanilla JS PWA + Capacitor Android shell (one shared core) | Reuses extension UMD engine libs directly; no rewrite |
| Scraping on phone | Android only, via WebView with **desktop user-agent** on `affiliate.shopee.com.my` | Portal DOM = desktop Ant Design classes; iOS cannot sideload WebViews |
| Backend | **GitHub private repo as DB** (`muhaafidz/shopithread-sync`, `data.json` via Contents API) — no Cloudflare | Single user; zero new infra; versioned history free; deployable via gh CLI |
| Sync auth | Fine-grained PAT scoped to `shopithread-sync` only (Contents: RW), stored per-device | Least privilege; rotation in seconds |
| Sync payload | Product data + queue captions ONLY — never cookies/tokens/keys | Security invariant |
| Content generation | Deterministic 7-template BM rojak engine (default) + **AI mode via OpenRouter, BYO key, Gemini Flash default** (`google/gemini-2.5-flash`) | Offline-first; AI optional, key stays on device |
| Multi-account | Level 1 = in-app account profiles + intent posting (shipped) · Level 2 = Threads API auto-post (later, needs tokens server-side) | Meta intent has no account param — app posts as active profile |
| Posting | Official `threads.com/intent/post?text=…` — opens Threads app pre-filled on phones (Meta-documented); images attached manually | No ToS gray zone for posting; nothing auto-submitted |

**Repos:**
- `muhaafidz/shopithread` — desktop extension (MY fork)
- `muhaafidz/shopithread-mobile` — this PWA (GH Pages)
- `muhaafidz/shopithread-sync` — private sync store (data.json)

## ⬜ Phase 3 — Android APK (NEXT)
Concrete checklist:
1. Add Capacitor to `shopithread-mobile` (`npm i @capacitor/core @capacitor/cli @capacitor/android`)
   - `npx cap init` (appId `my.muhaafidz.shopithread`, webDir `.` or `dist/`)
   - `npx cap add android`
2. Scraper screen (new `js/scraper.js` + native bridge):
   - WebView screen loading `https://affiliate.shopee.com.my/offer/product_offer` with **desktop Chrome UA** + desktop viewport
   - Inject `vendor/shopee-scraper-service.js` logic (copy from extension) after login; expose `ShopiThreadMarket` config
   - Scrape → save to local IndexedDB → also offer Push to sync repo
   - Progress UI ported from extension's `content.js` panel (page count 1-10, delay 400/600/1000ms)
3. **Hardening (must):** JS bridge only on `*.shopee.com.my` allowlist; no file access from file URLs; NEVER `onReceivedSslError→proceed()`; cookies stay device-local; desktop UA only for affiliate origin
4. Save product photo → device gallery (Capacitor Filesystem/Media or download prompt)
5. CI build: `.github/workflows/android.yml` — JDK 17 + Android SDK (preinstalled on ubuntu runners) → `cap sync && ./gradlew assembleRelease` → sign with keystore stored as GH secret (base64) → attach APK to GitHub Release
   - Keystore: generate once (`keytool`), store `KEYSTORE_BASE64` + passwords as repo secrets
6. Distribution: user installs APK from GitHub Releases on phone (sideload)
